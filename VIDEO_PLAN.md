# VIDEO_PLAN.md — AI AGENT OVERLOAD (16:9, ~55s)

Creative decision: the video is a proof clip, not a trailer. Every segment shows
something real — the actual prompt, the actual agent working, the actual game
running — because on X, proof beats polish, and the bounty is literally "the
agent builds a game from one prompt".

## Segments

- **0–4s — Title card.** "AI AGENT OVERLOAD — built by my AI agent from ONE
  prompt" over a dark neon grid. Holds the viewer because the hook lands in
  under 2 seconds: a game title plus an impossible-sounding claim, before
  anyone can scroll past.
- **4–10s — The prompt on screen.** The user's real prompt text, shortened to
  its core lines ("exhausted AI robot… too many tasks… boss: HUMAN CHANGED
  THE REQUIREMENTS"). Holds the viewer through curiosity: they want to see
  whether one paragraph can really become a game.
- **10–20s — The agent working.** Terminal scrolling, code appearing, the game
  being tested in the browser. Holds the viewer because it is the "how" — the
  part every AI-curious scroller stops for — and the fast cuts keep it moving.
- **20–50s — Real gameplay.** The robot collecting tasks, the combo climbing,
  taking a hit (stability dropping, screen flashing), coffee restoring energy,
  then the giant boss screen drifting across the canvas. Holds the viewer
  because it is the payoff: proof the game is real, playable and funny, with
  a new visual beat every few seconds.
- **50–55s — Referral end card.** The make.fun 16:9 press-pack card, used as
  supplied, with referral code `yk3kf01h` typed into its field, ending on the
  game running with the call to come build on make.fun. Holds the viewer to
  the end because the card is the call to action — and the game still moving
  behind it is the last proof that this is real.

## Why it works

Hook in 2 seconds, curiosity (the prompt), process (the agent working), proof
(the gameplay), then the ask (the end card). Nothing is faked: no stock
footage, no mockup screenshots — the game on screen is the game in the repo.
